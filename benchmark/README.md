# benchmark

実験コードの計算性能（実行時間・メモリ・スケーリング）の計測。物理的・数値的な結果は `analysis/` で扱い，
ここでは「どのくらいの規模まで・どのくらいの時間で回せるか」を見積もるために使う。

```
benchmark/
  bench_<name>.py         計測スクリプト（マシン名を引数で受け取る）
  plot_<name>.py          計測結果の作図
  results/<name>/<machine>.csv
  figs/<name>/
```

- 結果の CSV にはマシン名・コア数・ライブラリのバージョンも列として残す
- 本番スイープの前に小さいサイズで計測し，`PARALLEL` やスイープ範囲を決める根拠にする
